# Course roadmap

## Current learning path

- Beginner: execution model and workflow syntax.
- Intermediate: reusable design and deployment patterns.
- Advanced: security, reliability, debugging, and operations.
- Learning Hub: filtered curriculum map, lesson views, checkpoints, and local progress.
- Full quiz: eighteen multi-answer questions with explanations and source links.

## Planned depth

- Add a local `actionlint` workshop with intentionally broken workflows.
- Add a composite-action lesson and compare it experimentally with reusable workflows.
- Add artifact attestations and release provenance exercises.
- Add a self-hosted runner hardening lab using an isolated disposable environment.
- Add an enterprise governance module covering required workflows, rulesets, audit evidence, and platform ownership.

Roadmap items are proposals, not commitments. Contributions should preserve credential-free default execution and the lesson-owned structure.
