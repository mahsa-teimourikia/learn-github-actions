# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository when available, or contact the repository owner privately through the profile linked from the repository.

Include the affected file, a minimal reproduction, impact, and any suggested mitigation. Do not include live credentials, tokens, or sensitive logs.

## Educational examples

The workflows use placeholders and readable major-version action references for teaching. Before production use, replace placeholders, pin third-party actions to reviewed full commit SHAs, configure protected environments, and review every permission and external side effect.
