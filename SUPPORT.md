# Support

For setup and execution problems, first check the troubleshooting sections in
[INSTALLATION.md](INSTALLATION.md#troubleshooting-installation) and
[RUN_GUIDE.md](RUN_GUIDE.md#troubleshooting-runs).

- For a lesson correction or broken link, open a content-improvement issue.
- For a reproducible course bug, open a bug report and include the operating system, runtime version, command, and output.
- For a new lesson or workflow pattern, open a feature request before a large contribution.
- For suspected security problems, follow [SECURITY.md](SECURITY.md) and report privately.

General GitHub Actions product support belongs in the [official GitHub documentation](https://docs.github.com/en/actions) or GitHub Support, not this course repository.
